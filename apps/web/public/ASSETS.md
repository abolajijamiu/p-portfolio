# Logo assets

Place the following files in this directory:

| File             | Use                              | Format  |
|------------------|----------------------------------|---------|
| `favicon.png`    | Browser tab icon                 | PNG 512×512 or 32×32 |
| `logo-mark.png`  | E mark only (nav, small contexts)| PNG with transparent background |
| `logo-light.png` | Full wordmark on dark bg         | PNG with transparent background |
| `logo-dark.png`  | Full wordmark on light bg        | PNG with transparent background |

## Notes
- Export all assets with transparent background (not black)
- favicon.png is already referenced in app/layout.tsx
- The E mark variant is for favicons and small-scale applications only
- Never use the logo mark without the wordmark at sizes above 48px
